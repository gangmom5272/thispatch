## 스크립트 (이 저장소)

| 파일 | 대상 | 하는 일 |
|---|---|---|
| `infra/01-common.sh` | EC2 2대 | Java · hosts · 디렉터리 · 커널 파라미터 (실행 완료) |
| `infra/02-postgres.sh` | 서버1 | PostgreSQL 17 · pgvector · pg_trgm (실행 완료) |
| `infra/04-wsl-node.sh` | 노트북 | `ROLE=master\|worker` — 패키지·설정·환경변수 전부 |
| `infra/05-wsl-route-fix.sh` | 노트북 | 기본 경로 교정 + systemd 타이머 |
| `infra/06-firewall.ps1` | 노트북 | Hyper-V 방화벽 인바운드 규칙 (관리자) |
| `infra/07-cluster.sh` | 마스터 | `format` `start` `stop` `status` `verify` `addworker` |
| `infra/08-systemd-hadoop.sh` | 노트북 | 데몬을 systemd 서비스로 등록 |
| `infra/09-wsl-keepalive.ps1` | 노트북 | WSL 유휴 자동 종료 해제 (관리자) |

`03-node-setup.sh` 는 EC2 를 클러스터 노드로 쓰는 전제로 쓴 것이라 쓰지 않습니다.

`09-wsl-keepalive.ps1` 은 WSL 유휴 자동 종료를 끕니다. 안 하면 터미널을 닫는 순간
그 노드가 클러스터에서 사라집니다.

## 워커가 실행할 순서

```bash
sudo bash infra/05-wsl-route-fix.sh
ROLE=worker MASTER_IP=70.12.108.81 bash infra/04-wsl-node.sh
sudo ROLE=worker bash infra/08-systemd-hadoop.sh
```

그리고 관리자 PowerShell 에서 `.\06-firewall.ps1`.

자세한 전제 조건과 주의점은 노션 페이지를 보세요.
