## 스크립트 (이 저장소)

| 파일 | 대상 | 하는 일 |
|---|---|---|
| `infra/scripts/01-common.sh` | EC2 2대 | Java · hosts · 디렉터리 · 커널 파라미터 (실행 완료) |
| `infra/scripts/02-postgres.sh` | 서버1 | PostgreSQL 17 · pgvector · pg_trgm (실행 완료) |
| `infra/scripts/04-wsl-node.sh` | 노트북 | `ROLE=master\|worker\|client` — 패키지·설정·환경변수 전부 |
| `infra/scripts/05-wsl-route-fix.sh` | 노트북 | 기본 경로 교정 + systemd 타이머 |
| `infra/scripts/06-firewall.ps1` | 노트북 | Hyper-V 방화벽 인바운드 규칙 (관리자) |
| `infra/scripts/07-cluster.sh` | 마스터 | `format` `start` `stop` `status` `verify` `addworker` `setmaster` |
| `infra/scripts/08-systemd-hadoop.sh` | 마스터·워커 | 데몬을 systemd 서비스로 등록. `client` 는 거부한다 |
| `infra/scripts/09-wsl-keepalive.ps1` | 마스터·워커 | WSL 유휴 자동 종료 해제 (관리자) |
| `infra/scripts/10-namenode-backup.sh` | 마스터 | NameNode 메타데이터를 서버2A 로 백업 (`now` `install` `list` `restore`) |

`09-wsl-keepalive.ps1` 은 WSL 유휴 자동 종료를 끕니다. 안 하면 터미널을 닫는 순간
그 노드가 클러스터에서 사라집니다. 데몬이 없는 `client` 에는 필요 없습니다.

## 워커가 실행할 순서 (노트북 2~5)

```bash
sudo bash infra/scripts/05-wsl-route-fix.sh
ROLE=worker MASTER_IP=70.12.108.85 bash infra/scripts/04-wsl-node.sh
sudo ROLE=worker bash infra/scripts/08-systemd-hadoop.sh
```

그리고 관리자 PowerShell 에서 `.\06-firewall.ps1` 과 `.\09-wsl-keepalive.ps1`.

## AI 노트북이 실행할 순서 (노트북6)

```bash
sudo bash infra/scripts/05-wsl-route-fix.sh
ROLE=client MASTER_IP=70.12.108.85 bash infra/scripts/04-wsl-node.sh
```

여기서 끝입니다. `07` `08` `09` 는 돌리지 않습니다.
`06-firewall.ps1` 은 `--master yarn` 을 client 모드로 쓸 때만 필요합니다.

자세한 전제 조건과 주의점은 노션 페이지를 보세요.
