## 바꾼 내용

- 실제 공지의 자연어 날짜·시각, 명시된 KST/JST/UTC 오프셋을 읽는다.
- 점검 공지의 제목과 본문 날짜가 일치하고 변경 완료 근거가 있을 때 날짜를 연결한다.
- 서버 오류의 수정 완료 표현을 패치 분류 근거로 인식한다.
- 모바일/혼합 공지에서도 명시적인 Steam 버전 완료 줄의 날짜는 따로 검사한다.
- 적용일 근거가 없지만 현재 패치라는 근거가 있는 경우에 한해 게시일을 **추정**으로 반환한다.
- 버전 숫자, 예정·점검 일정, 알파·데모, 다른 플랫폼 날짜가 잘못 섞이지 않도록 보류한다.
- “재시작하면 업데이트가 적용된다”는 설치 안내를 서버 배포 예정과 구분한다.
